MY BABIES — PROFESSIONAL WEBSITE

1. Upload the CONTENTS of this folder to the ROOT of your GitHub repository (not the ZIP file itself).
2. Make sure index.html and style.css are in the repository root.
3. Make sure the entire assets folder is uploaded, including assets/images/product-01.jpg through product-78.jpg.
4. GitHub: Settings → Pages → Deploy from branch → main → /(root) → Save.
5. WhatsApp: open index.html and replace const WHATSAPP_NUMBER = ""; with your South African WhatsApp number in international format, e.g. 2782XXXXXXX (no +, spaces or dashes).
6. The address used on the site is: Mzansi zonke bonke, 31 Gerard Sekoto St, Johannesburg, 2001.

The product photos are bundled locally with the website, so the website does not depend on external image hosting.
